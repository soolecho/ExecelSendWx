# 表格自动发送By春风予Lu

基于 PyQt6 开发的 Excel 表格数据自动提取并通过微信发送的自动化工具，
内置定时调度器、托盘驻留、单实例锁、Nuitka standalone 打包与
Inno Setup + Authenticode 自签名安装包发布流程。

当前版本：**v1.5.5**（春风予Lu 自签名 SHA256 证书，指纹
`191C64E4EC07377CA032878878D0A45F554C8146`）。

## v1.5.5 更新内容

- **修复联系人映射把带逗号的名字拆分导致映射失效**：映射表第一列填
  `"孙中枢,孙中枢"`（引号包裹、名字本身含逗号）时，导入/发送前重载
  应作为**一条整体来源值** `孙中枢,孙中枢` 命中对应接收人；此前普通
  联系人映射与全量默认映射导入行为不一致，带逗号名字会被错拆成
  `"孙中枢` 与 `孙中枢"`，映射对不上、按原名发送。现两处拆分逻辑
  统一为引号感知（引号内分隔符不生效），手动导入、发送前自动重载、
  定时/配置链路全部生效。
- **修复全量默认映射兜底被「最近使用的配置」抢占**：手动任务关闭了
  当前配置的「启用联系人映射」后，本应走到全量默认映射兜底；此前会
  被「最近使用的配置」里其他仍启用映射的配置抢先恢复，导致全量兜底
  永远轮不到。现显式加载了配置时只认当前配置自身的映射，关闭后直接
  落到全量默认映射。

## v1.5.4 更新内容

- **监控新增「写入智能表格(AirScript)」**：轮询任务生成的数据可自动追加写入
  自己的金山智能表格，作为与微信发送并列的可选出口。
  - **独立凭证**：使用脚本 webhook + AirScript-Token，与现有 wps_sid 读取链路
    完全独立，互不影响。
  - **追加写入**：去掉首行标题，在指定 sheet 的几列中从**最后一个非空行的下一行**
    往下逐行写入；写入位置自动跟随表格原有格式。
  - **可配置**：Webhook / 脚本令牌 / 目标 Sheet / 起始列 / 写入列数均可设置，
    列数填 0 表示写入全部列。
  - 写入失败保留基线，下次轮询自动重试同一批新增；旧监控配置自动兼容。

## v1.4.23 更新内容

- **发送前自动恢复过小的微信窗口**：微信主窗口被拖得很小（宽度 < 600 或
  高度 < 450）时，顶部搜索框会被压缩/隐藏，UIA 读不到搜索框 → 预检
  「找不到微信搜索框」→ 跳过验证 → 切换窗口失败 → 发送失败（日志表现为

  激活窗口后检测主窗口尺寸，过小则自动放大到所在显示器工作区的 90% 并
  居中，恢复搜索框后再继续预检与发送；窗口尺寸正常时保持原样不动。

## 使用说明

### 数据发送 Tab

1. **选择数据来源**：本地 Excel（`.xlsx` / `.xls`）或金山云文档。
   云文档首次使用需在「Cookie 凭证设置」中粘贴浏览器的 `wps_sid`，
   可直接输入文档链接/ID 或点「浏览…」从云端表格列表选择
2. **选择 Sheet**：从下拉框选择需要处理的工作表（云文档会先下载到
   临时文件，读取完成后自动删除）
3. **选择列**：设置人员列、提取列，以及可选的微信昵称列
4. **加载数据**：读取人员列表并选择本次需要发送的人员
5. **设置发送方式**：选择文字、图片或图片后文字，并设置发送延迟
6. **设置自定义消息**：按需启用数据发送后的追加消息
7. **保存配置**：保存当前来源、Sheet、列、筛选和发送设置；
   勾选「加载本配置后自动全选筛选人员并直接发送」后，以后每次
   加载该配置都会自动发送，无需手动确认
8. **开始发送**：确认人员列表后开始发送；失败任务可单独重试

### 定时发送 Tab

1. **新建任务**：填写任务名称并选择任务类型：
   - **发送文字消息**：填写接收人和消息内容（可带附件）
   - **执行表格配置**：添加一个或多个「数据发送」保存的配置文件
     （本地表格和云文档配置都支持），多个配置按列表顺序链式执行，
     可上移/下移调整顺序，执行时跑完一个再跑下一个
2. **设置周期**：勾选周一至周日，添加多个时间点（`QTimeEdit`）
3. **设置发送参数**：人员间隔、聊天窗口延迟、是否启用自定义消息
   （仅文字消息类型；表格配置类型使用各配置自己的发送设置）
4. **启用任务**：勾选启用后，后台 `ScheduleDispatcher` 每 10 秒
   tick 一次，命中时间窗口（±20 秒）且当日未触发过即执行
5. **导入/导出**：支持把全部任务导出为
   `{version:1, type:schedule_profile, saved_at, tasks:[...]}` JSON，
   在另一台机器上覆盖或追加导入

表格配置类型任务的接收人、筛选条件、发送顺序、间隔均以每个配置
自身的设置为准；若配置勾选了 auto_send 不影响定时执行（定时按
配置筛选结果全员发送）。

调度器在程序退出时会等待当前正在发送的子任务完成，再安全停止；
重复触发的 slot 不会重写 JSON，只新增 slot 才落盘并刷新 `updated_at`。

### 监控发送 Tab（企微群文件自动推送）

监控企业微信客户端「聊天文件自动下载」保存到本地目录的文件，按规则
筛选/清洗后自动推送文字、图片或生成的表格给指定微信接收人：

1. **监控目录与文件匹配**：选择本地目录，可填文件匹配通配符（如
   `*.xlsx;*.xls`）；勾选「包含子文件夹」可递归扫描子目录
2. **筛选与对比**：指定「筛选与对比」的列名和取值；开启增量对比时，
   每个轮询周期只读取「时间最新」的那个文件，基于已记录基线做行增量，
   只推送新增内容；关闭对比则按文件指纹识别新文件
3. **数据清洗**：在「列设置」中对指定列配置去空格、去非数字、取前 N
   位、前缀校验等规则，校验失败的行可剔除或保留并记录日志
4. **提取列与推送内容**：可手动设置要提取的列；文字推送支持自定义标题，
   并可只显示「新增条数」而隐藏逐行明细
5. **每天运行时间段**：时间窗可勾选「限定每天时段」并设起止时间
   （支持跨夜），空档期不扫描不推送；未勾选=全天
6. **独立配置文件**：每个监控任务一个独立 JSON，可同时运行多个不同的
   监控配置文件；失败推送会弹右下角常驻提醒

监控配置目录为 `%LOCALAPPDATA%\ExcelSendWx\monitors\profiles`，
轮询后台线程常驻，每 30 秒扫一次并按各任务自身间隔节流。

## 配置管理

左侧「配置管理」支持：

- **保存配置**：更新当前已经加载的配置文件
- **另存为配置**：创建新的 JSON 配置，可保存多个不同任务
- **加载配置**：读取配置后自动打开 Excel、切换 Sheet、恢复列和发送设置
- **最近配置**：双击最近列表中的配置即可加载

配置中会保存：

- 数据来源（本地 Excel 路径 / 金山云文档 ID 与名称）和 Sheet
- 表头所在行号（默认第 1 行；分类标题在第 2 行或更靠下时可自行指定）
- 人员列、微信昵称列和提取列
- 筛选条件
- 手动指定的微信接收人
- 文字、图片或图片后文字的发送形式、发送顺序和附件
- 人员发送间隔和聊天窗口延迟
- 自定义消息开关及内容
- 加载配置后是否自动全选并发送（auto_send）

默认配置目录为 `%LOCALAPPDATA%\ExcelSendWx\profiles`，定时任务目录为
`%LOCALAPPDATA%\ExcelSendWx\schedules`，两者独立互不污染。
如果 Excel 文件被移动，加载配置时可以重新定位文件；如果表格列发生
变化，程序会提示缺失列。

## 日志与临时文件

- 运行日志：`%LOCALAPPDATA%\ExcelSendWx\logs\app.log`
- 日志单文件最大 5 MB，保留 3 个历史文件
- 打包日志：`logs/build_nuitka_YYYYMMDD_HHMMSS.log`、
  `logs/build_installer_YYYYMMDD_HHMMSS.log`
- 表格图片临时目录：`%TEMP%\wxauto_images`
- 临时图片在发送完成、失败或停止后自动删除

## 技术栈

- **GUI 框架**：PyQt6
- **数据处理**：python-calamine（Rust 高速引擎，大表格首选）+ pandas + openpyxl（兜底）
- **云文档**：金山文档开放接口（`wps_sid` Cookie + requests）
- **微信自动化**：wxauto4
- **打包工具**：Nuitka 4.1.x（standalone + pyqt6/tk-inter 插件）
- **安装包**：Inno Setup 6 + Authenticode SHA256 自签名 +
  Digicert 时间戳

## 注意事项

1. 使用前请确保微信 PC 客户端已登录
2. 微信联系人使用模糊搜索，请确保保存的昵称能够正确匹配目标
3. 建议先使用少量联系人测试配置和发送内容
4. 发送过程中尽量不要操作微信窗口、鼠标和键盘
5. Nuitka 版本必须携带整个 `main.dist` 目录运行
6. 点击窗口右上角关闭按钮只会隐藏到托盘
7. 完全退出程序请右键托盘图标并选择「退出程序」
8. 安装包通过 `表格自动发送安装包_v1.3.3.exe` 安装，可在安装时勾选
   「开机自启动」，安装后通过控制面板卸载；卸载器同样已签名
